# Чат MAX на GREEN-API

Тестовое задание на позицию "Фронтенд разработчик React". Это простой веб-чат, через который можно
отправлять и получать текстовые сообщения в MAX с помощью [GREEN-API](https://green-api.com/max).
Внешний вид делал по образцу [web.max.ru](https://web.max.ru/), цвета взял оттуда же. Тема (светлая или
тёмная) подхватывается из настроек системы.

Демо: https://fry-alt.github.io/green-api-max-chat/

## Как пользоваться

1. Ввести `idInstance` и `apiTokenInstance` из [личного кабинета GREEN-API](https://console.green-api.com).
   Адрес API подставится сам по первым цифрам `idInstance` (например, для инстанса `3100...` это
   `https://3100.api.green-api.com`). Если у вас другой адрес, его можно поменять руками.
2. Ввести номер получателя, `+7...` или `+375...`. Откроется чат.
3. Написать сообщение и нажать Enter. Shift+Enter переносит строку.
4. Когда собеседник ответит в MAX, ответ появится в чате. Если напишет кто-то новый, чат с ним
   сам появится в списке.

### Что проверить в настройках инстанса

Инстанс должен быть авторизован через QR-код. Кроме этого:

- поле webhookUrl должно быть пустым, иначе GREEN-API не отдаёт уведомления через HTTP API;
- должна быть включена галочка "Получать уведомления о входящих сообщениях и файлах";
- можно включить ещё "уведомления о сообщениях, отправленных с телефона", тогда в чате будет видно и то,
  что вы написали в самом приложении MAX.

Если с настройками что-то не так, приложение напишет об этом при входе или в плашке над списком чатов.

## Запуск локально

Нужен Node.js 20.19+ или 22+.

```bash
npm install
npm run dev        # откроется на http://localhost:5173
npm test           # тесты (Vitest)
npm run build      # сборка в dist/
```

## Как устроено

Основная логика лежит отдельно от компонентов, чтобы её можно было нормально тестировать:

- `src/api/greenApi.ts` - клиент для GREEN-API. Тут все запросы (`getStateInstance`, `getSettings`,
  `checkAccount`, `sendMessage`, `receiveNotification`, `deleteNotification`) и перевод кодов ошибок
  в понятные сообщения.
- `src/lib/poller.ts` - цикл получения уведомлений.
- `src/lib/notifications.ts` - вытаскивает из уведомления текстовое сообщение.
- `src/state/chats.ts` - состояние чатов, обычный reducer.
- `src/components/` - экран входа, список чатов и окно переписки.

### Отправка

Сообщения уходят методом [SendMessage](https://green-api.com/v3/docs/api/sending/SendMessage/).
Перед этим чат создаётся через [CheckAccount](https://green-api.com/v3/docs/api/service/CheckAccount/).
Можно было бы слать просто на номер (`79991234567@c.us`), но в MAX (v3) у чата свой числовой id,
и ответы приходят именно с ним. Поэтому номер сначала превращается в chatId, и дальше всё работает через него.

Сообщение появляется в чате сразу, с часиками. Когда API ответил, часики меняются на галочку.
Если отправка не прошла, под сообщением будет кнопка "Повторить".

### Получение

Сделано через [HTTP API](https://green-api.com/v3/docs/api/receiving/technology-http-api/):
`receiveNotification`, потом обработка, потом `deleteNotification`. Запрос висит до 20 секунд
(`receiveTimeout=20`), так что сервер не дёргается каждую секунду впустую.

Что пришлось учесть:

- Уведомление удаляю из очереди, даже если не получилось его разобрать. Иначе очередь застрянет на нём
  и новые сообщения перестанут приходить.
- Если удалить не получилось, то же уведомление придёт ещё раз. Чтобы не было дублей, сообщения
  сверяются по `idMessage`.
- Уведомление о нашем же отправленном сообщении иногда приходит раньше, чем ответ на `sendMessage`.
  Это тоже учтено, второй копии сообщения не будет.
- Если пропал интернет, запросы повторяются с паузой, которая растёт с 1 до 15 секунд. В шапке
  в это время написано "переподключение...".
- При выходе из аккаунта текущий запрос отменяется через `AbortController`, чтобы не висел в фоне.

### Где хранятся данные

Данные для входа и переписка лежат в `sessionStorage`. После перезагрузки страницы всё на месте,
а после закрытия вкладки стирается. Токен уходит только в GREEN-API. Своего бэкенда нет, он не нужен:
GREEN-API разрешает запросы прямо из браузера.

### Чего нет

- Только текст и только личные чаты, как в задании. Файлы и группы просто пропускаются.
- Если открыть чат в двух вкладках, сообщения разойдутся между ними: очередь уведомлений у инстанса одна.
- Старая переписка не подгружается, видно только то, что пришло после входа (и то, что уже лежало в
  очереди, она хранится 24 часа).
